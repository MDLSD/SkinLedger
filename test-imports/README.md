## Что уже нашлось на прогоне

**1. «Просто текст» ≠ произвольный текст (файл 10).** Поле текста уходит в
`parseCsv`, который всегда режет по табу/`;`/`,`. Проза распадается по запятым:
из 5 предложений 2 отброшены как мусор, у остальных распознано только
«Название» (всё предложение целиком), цены нет → импорт откажет с «Укажите
колонки Название и Цена покупки». Если обещание «принимает просто текст»
означает вставку из Excel/Google Sheets — всё ок (файл 02). Если имелась в виду
проза — этой ветки нет.

**2. Несуществующие даты проходят молча (файл 09, строка 10).** `parseDate`
проверяет только `день ≤ 31`, поэтому `30.02.2026` → строка `2026-02-30`, а
`z.coerce.date()` превращает её в **2 марта 2026**. Сделка импортируется с
неверной датой без предупреждения.

## Как гонять

Файлы 01, 03–09 — грузить как файл. Файл 02 и 10 — копировать содержимое в поле
вставки текста. После каждого прогона проверять: превью → сопоставление колонок
→ импорт → откат (undo) чистит ровно импортированные сделки.

Побочный эффект: импорт создаёт кастомные площадки для незнакомых названий
(Buff163, Skinport, CS.MONEY, market csgo…) — после серии тестов их накопится
десяток, чистить вручную.
