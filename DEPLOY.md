# Деплой SkinLedger (чек-лист)

## Переменные окружения (прод)

- [ ] `AUTH_SECRET` — сгенерировать: `openssl rand -base64 32`.
- [ ] `DATABASE_URL` — Postgres (Neon/Supabase), не SQLite.
- [ ] **`AUTH_URL`** — публичный адрес приложения, например `https://skinledger.app`.
      Без него при `trustHost: true` базовый URL для callback/redirect собирается из
      заголовка `Host`, то есть `Host: evil.com` его подменяет. Заодно фиксирует
      протокол независимо от того, выставляет ли прокси `x-forwarded-proto`.
- [ ] **`TRUST_PROXY=true`** — ⚠️ **обязательно за доверенным прокси (Vercel/nginx).**
      Без него все клиенты делят один ключ rate-limit `"unknown"`: подделку IP это
      не пропускает (fail-closed), но один атакующий 5 запросами блокирует
      **регистрацию всем** на час, ~30/мин — вход (см. `src/lib/client-ip.ts`).
      За прокси, который перезаписывает `x-forwarded-for` реальным IP, лимит снова
      работает per-IP.

- [ ] **Перед горизонтальным масштабированием** заменить in-memory лимитер

      **Не запускать `npm audit fix --force`** — он предлагает `next@9.3.3`,

- [ ] `xlsx` подключён из официального CDN SheetJS (`https://cdn.sheetjs.com/...tgz`,

      high-severity prototype-pollution. На сборке нужен доступ к `cdn.sheetjs.com`
      при `npm install`. При обновлении — брать новую версию тоже с CDN SheetJS.

## Локализация (найдено ревью i18n от 2026-08-05)

Инфраструктура и перевод интерфейса в порядке: словари ru/en совпадают ключ
в ключ, приватная зона закрыта и под префиксом (`/en/app` → `/en/login`), CSP
с nonce жив, hreflang и canonical на месте, ошибки серверных действий
переводятся. Ниже — что осталось починить перед релизом.

- [ ] **`"Не указана"` протекает в английский интерфейс.** Площадка-заглушка
      для строк импорта без площадки (`src/lib/actions/import.ts`) хранится
      в БД под русским именем, поэтому видна англоязычному пользователю
      в фильтре сделок и в списке площадок формы. Варианты: хранить служебный
      маркер (пустое имя/флаг) и переводить на выводе, либо назвать нейтрально
      («—» / «Unknown»). Учесть, что у существующих пользователей запись уже
      создана — понадобится миграция данных.
- [ ] **`src/app/global-error.tsx` остался на русском.** Он вне `[locale]` и
      сам рендерит `<html>`, поэтому next-intl там недоступен, — но именно эту
      страницу увидит англоязычный пользователь при падении приложения.
      Чинится чтением cookie `NEXT_LOCALE` на клиенте и парой строк словаря
      прямо в файле.
- [ ] **Решить, оставлять ли автоперенаправление по `Accept-Language`**
      (`localeDetection` включён по умолчанию в `src/i18n/routing.ts`). Запрос
      `/skins/...` с `Accept-Language: en` отдаёт 307 на `/en/skins/...`.
      Googlebot ходит без этого заголовка и получает русскую версию (проверено),
      но краулеры и превью-боты соцсетей с английским заголовком будут получать
      редирект с канонического русского адреса. Если это нежелательно —
      `localeDetection: false` и переключение только вручную.

Известное поведение, не баг: после первого переключения языка next-intl ставит
cookie `NEXT_LOCALE`, и дальше все беспрефиксные адреса (`/login`, `/skins/…`)
уводят в выбранную локаль.

Гоча разработки: после переезда `app/` под `app/[locale]/` dev-сервер отдаёт
404 на все маршруты, пока не удалить `.next/dev`. Прод-сборка при этом зелёная.

## Тарифы

Лимиты бесплатного тарифа заданы в одном месте — `src/lib/plan.ts`
(`PLAN_LIMITS`). Тариф хранится в `User.plan` + `User.planUntil`; просроченный
`pro` автоматически считается бесплатным, отдельного задания по расписанию для
этого не нужно.

- [ ] **Подключить оплату.** Кнопка на `/app/billing` пока только заводит
      заявку в таблице `Lead` (`feature: "pro"`), а тариф переключается в БД
      вручную:
      `UPDATE User SET plan='pro', plan_until=… WHERE email=…`.
      Перед релизом — платёжный провайдер и вебхук, который проставляет
      `planUntil`. Заявки из `Lead` — первые кандидаты на письмо о запуске.
- [ ] **Задержка обновления цен для бесплатного тарифа** (третий вариант
      ограничения из ТЗ 6) не сделана: нужен отдельный слой устаревших
      котировок поверх `PriceHistory`. Держим в запасе, если потолка цены
      (2 $) и трёх площадок окажется мало.
- [ ] Проверить набор бесплатных площадок (`FREE_SOURCE_ORDER`) после
      подключения реального источника цен: слаги должны существовать
      в `MarketSource`, иначе набор доберётся произвольными площадками.
